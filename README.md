## Требования к платформе

- **1С:Предприятие 8.3.27.XXXX**
  - минимальная версия платформы — **8.3.27.2025**
  - используемая при разработке — **8.3.27.2214**
- Режим совместимости конфигурации — **8.3.27**
- Основной режим запуска — управляемое приложение, вариант встроенного языка — русский
